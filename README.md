# StarRailRes

Honkai: Star Rail game resources.


## Overview

Index files structure:


```text
StarRailRes
└─ index_new
   └─ [language]
      ├─ paths.json                     # path 
      ├─ elements.json                  # element 
      ├─ properties.json                # property 
      ├─ characters.json                # character basic info 
      ├─ character_ranks.json           # character rank 
      ├─ character_skills.json          # character skill
      ├─ character_skill_trees.json     # character skill tree
      ├─ character_promotions.json      # character promotion and level
      ├─ light_cones.json               # light cone
      ├─ light_cone_ranks.json          # light cone rank
      ├─ light_cone_promotions.json     # light cone promotion and level
      ├─ relics.json                    # relic basic info
      ├─ relic_sets.json                # relic set
      ├─ relic_main_affixs.json         # relic main affix
      ├─ relic_sub_affixs.json          # relic sub affix
      └─ items.json                     # material
```

The file structure of this project is as follows:


```text
StarRailRes
├─ icon         # icon folder
├─ image        # image folder
├─ guide        # guide image folder
├─ index_new    # index files folder
└─ index_min    # compressed index files folder
```
